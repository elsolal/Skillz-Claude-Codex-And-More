# v6.1 migration — RALPH removal

Skillz-Claude v6.1 removes RALPH and all autonomous commands: `/auto-loop`, `/auto-discovery`,
`/auto-dev`, `/cancel-ralph` and `/resume-ralph`. The stop hook and active session-state contract are
also removed. Interactive `/discovery`, `/dev`, `/quick-fix`, `/ship` and the bounded quality gate
remain the supported workflow.

## Safe update behavior

`install.sh update` removes an old command, hook or generated settings sidecar only when its current
SHA-256 still matches the last Skillz-owned v6 bytes. A modified file is preserved and reported.
An untouched legacy `settings.json` is replaced with the v6.1 settings; a modified one is preserved
for manual review. Local `.codex/hooks.json`, `.codex/hooks/` and other files without Skillz
ownership proof are never scanned or deleted by this migration.

The checksum manifest is `.claude/migrations/v6.1-removed-artifacts.sha256`. It is historical
migration evidence, not a runtime feature flag.

## Manual cleanup for preserved state

Session logs under `docs/ralph-logs/` and `.claude/ralph-state.json` may contain user history or
unfinished work, so the updater does not delete them automatically. Archive or remove them only
after confirming they are no longer needed.

If the updater reports a modified legacy command or hook, compare it with this release, preserve
any user logic elsewhere, then remove the obsolete file manually. Do not copy the autonomous loop
back into active commands or settings.

## Replacement workflow

- Planning: run `/discovery`; approve the consolidated spec at its final checkpoint.
- Development: run `/dev`; approve the single implementation plan checkpoint.
- Verification: require executable manifest evidence and a committed quality gate.
- Long-running work: split it into explicit stories and resume from Git state and gate evidence.
